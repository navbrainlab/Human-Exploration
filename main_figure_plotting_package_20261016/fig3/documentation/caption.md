**Fig. 3 | Uncertainty and exploration across tasks.**

**a,** Pre-trial total exposure-based uncertainty (solid task-coloured lines) and percentage of DIS trials (purple dashed lines) over normalized learning progress. Within each of ten progress bins, observations were averaged within participants and then across participants; bands show pointwise normal 95% confidence intervals (1.96 × SEM). Task 1 includes its four-dimensional phases (4D-E and 4D-NE; 105 participants, 3,955 trials); Task 2 includes Obs and NObs (80 participants, 4,111 trials).

**b,** Probability of a DIS choice on a dimension at each within-trial uncertainty rank, averaged within and then across participants (mean ± SEM; n = 105 and 80). Rank 1 denotes the lowest uncertainty; trials without DIS contribute zero at every rank. Stars compare each later rank with rank 1 using source one-sided paired Wilcoxon signed-rank tests with Benjamini–Hochberg correction within task.

**c,** Pre-trial maximum dimensional uncertainty around every DIS trial and progress-matched other trials, reproducing the supplied Figure 9 event tables. Curves show event-weighted means ± SEM over available event windows, displaying offsets −3 to +3 (the frozen source retains ±5 trials) (1,516 DIS and 1,516 other triggers in Task 1; 1,849 of each in Task 2). Adjacent plots show mean ± SEM of participant-mean reductions from the trigger to trial +3. Task-specific y-axis scales are labeled; double slashes mark omitted zero intervals. Source two-sided Mann–Whitney U tests with Benjamini–Hochberg correction across tasks are retained: Task 1, n = 105/91, U = 6,448, adjusted P = 4.96 × 10⁻⁵; Task 2, n = 79/78, U = 3,996, adjusted P = 0.00132. Controls were pooled across participants within progress bins. Participant sets overlap, and incomplete windows are retained; see Methods for limitations. These are all-DIS-trigger, not bout-onset, analyses.

The c summary annotation, Δ Max. dim. uncertainty, denotes Umax(0) − Umax(+3): positive values indicate a reduction in maximum dimensional uncertainty. This definition and its statistics are unchanged by the shorter display window.

**d,** Conceptual definition of the exploration index (EI), redrawn from the supplied schematic. Solid arrows connect observed choices C(t−1), C(t) and C(t+1); the dashed purple branch leads to the predicted optimum C*(t+1). EI is the distance d between the actual next choice and this reference in the analysis's choice/feature representation. Node positions and the distance marker are illustrative, not empirical coordinates. This is not a DGEM prediction or a newly calculated optimum. The original task-specific EI values and temporal alignment are retained in e and f.

**e,** Stored exploration index and percentage of DIS trials over 12 bins of absolute trial number, with bin centres rescaled to 0–1. Solid curves and bands show pooled-trial index means ± SEM; purple curves and bands show percentage of DIS trials ± binomial SE among the same index-valid trials (3,850 Task 1 trials; 4,031 Task 2 trials).

**f,** Pooled trial distributions of the squared stored exploration index, separately for DIS and Others. Gaussian KDEs use relative bandwidth 0.45 and every valid observation; task-specific units and scales are retained. The Task 1 density ordinate is expressed in units of 10⁻³. Stars summarize a separate participant-level comparison of mean squared index between DIS and other trials, using two-sided paired Wilcoxon signed-rank tests with Benjamini–Hochberg correction across tasks (Task 1, n = 104 pairs, adjusted P = 4.16 × 10⁻¹⁶; Task 2, n = 79 pairs, adjusted P = 4.94 × 10⁻⁷). They do not test KDE shape. Only participants with both trial types enter these tests; all valid trials remain in the descriptive KDEs.

**g,** Saved participant-aggregate difference in exploration-term frequency between DIS context and the full report, followed by the seven most frequent exploration terms in DIS-associated interview context in each task. Points show mean differences per 1,000 tokens; horizontal intervals reproduce the supplied participant-bootstrap bounds, whose confidence level was not specified in the handover (Task 1, n = 72; Task 2, n = 69). Stars use saved BH-adjusted q values (0.002780 and 0.00011896). The full report includes DIS context. Two descriptive word clouds show Task 1 (left) and Task 2 (right), retaining all seven source-selected terms per task; the highest-frequency term is centered and the others surround it. Spatial positions are only for layout, not a measure of frequency or semantic similarity. Font size continuously increases with relative count r = count/task maximum, following 5 + 3√r pt. No separate size legend is shown. Colour identifies task; absolute token frequencies are not compared across tasks.

Double slashes mark omitted zero-to-lower-bound intervals. *P or q < 0.05, **< 0.01, ***< 0.001, under each panel's stated correction. Source Data include exact statistics, eligibility rules and interval definitions. DIS-frequency axes display percentages; frozen source proportions and bounds are multiplied by 100 for display only.
